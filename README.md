# Tlias 智能学习辅助系统（JavaWeb）

这是我在学习 JavaWeb 过程中，跟着网课敲的一个后台管理系统项目。

##  技术栈
- **后端**：Java 25, Spring Boot 4.0.9, MyBatis
- **数据库**：MySQL 8.0.46
- **构建工具**：Maven
- **前端**：ai

## 项目结构
- `tlias-web-management`：后端主模块
    - `controller`：控制层
    - `service`：业务逻辑层
    - `mapper`：数据访问层
    - `pojo`：实体类
